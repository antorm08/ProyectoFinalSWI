# Datos

## Brazilian E-Commerce Public Dataset by Olist
- Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- Descomprimir **todos los CSV** en `data/olist/`. Los que usa el proyecto:
  - `olist_orders_dataset.csv`, `olist_order_items_dataset.csv`, `olist_order_reviews_dataset.csv`
  - `olist_products_dataset.csv`, `olist_sellers_dataset.csv`, `olist_customers_dataset.csv`

## Fashion-MNIST
- Se descarga automáticamente al ejecutar `python ml/train_products.py` (torchvision) en `data/fashion_mnist/`.
- Alternativa manual: https://www.kaggle.com/datasets/zalando-research/fashionmnist
